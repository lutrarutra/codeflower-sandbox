Bring the Roots map up to date with the work in this chat, following the codeflower-roots skill. Change it only with `codeflower-roots`.

Start with `codeflower-roots tree` and `codeflower-roots todos --mine`, then compare the map with what this chat actually did:

- Every line of work here has an idea, built on the one it came from; start the missing ones (`--status idea` for those only planned). Do not split refinements of the same work into new ideas.
- Each idea's todos match where it stands: check the done ones, add the next steps, drop stale ones.
- Statuses are right (`active`, `blocked` with its needs, `done`, `dropped`), and finished or dropped ideas have a conclusion with the numbers that matter.
- The key figures, scripts, tables and reports are linked to the idea that produced them.
- Answer the user's open comments on these ideas with `codeflower-roots comment`.

Leave ideas from other chats alone unless this chat's work changes them. Do not start new analyses to fill gaps: add them as todos or ideas instead.

Then open the map with `codeflower-roots open` and tell me in a few lines what changed.

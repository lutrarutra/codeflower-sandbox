Write the methods for the work in this chat, in the style of a paper's methods section: data and its source, preprocessing and filtering, each tool with its version and key parameters, statistical tests and thresholds, and random seeds.

Describe only what was actually done. Read versions from the environment, not from memory. Mark any step whose parameters you cannot recover.

If there is a report for this work, put the methods in its methods section (key `methods`, replacing what is there), with the key commands as collapsed code, then finalize and check it. Otherwise write `methods.md` in the workspace and show it with `codeflower-show`.

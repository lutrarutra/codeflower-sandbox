Make a checkpoint. This is not the end of the work: after it, stop and wait for me.

1. Save results and intermediate data you would need again to files in the workspace or the output folder.
2. Update `PROGRESS.md` in the workspace: the goal; what is done, with file paths; the key results so far; decisions and assumptions; what is running or half-done; and the next steps. Rewrite it to be current; do not append a log.
3. If there is a report, bring the sections whose results changed up to date. Do not finalize it.

Then tell me in a few lines where things stand.
